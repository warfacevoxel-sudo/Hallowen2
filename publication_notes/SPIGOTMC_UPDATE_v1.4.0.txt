[SIZE=5][B][COLOR=#FFD700]✨ What's New in v1.4.0[/COLOR][/B][/SIZE]

[B][COLOR=#8B0000]🌑 New Darkness Event[/COLOR][/B]
Players will now experience random moments of darkness accompanied by terrifying sounds! This brief but impactful event adds another layer of spookiness to your server.

[LIST]
[*] [B]Screen Darkening:[/B] 1-second blindness effect (very visible!)
[*] [B]Layered Scary Sounds:[/B] Multiple iron trapdoor sounds + ambient cave sounds
[*] [B]Configurable:[/B] Default 10-50 minutes between events
[*] [B]Broadcast Messages:[/B] Random spooky messages
[*] [B]Auto-Merging:[/B] Updates automatically add new messages without overwriting yours!
[/LIST]

[B][COLOR=#8B0000]🍰 Progressive Cake Rewards[/COLOR][/B]
Helmet rewards are now progressive and repeatable!

[LIST]
[*] [B]1st reward:[/B] 3 minutes → Get cake
[*] [B]2nd reward:[/B] 6 minutes → Get cake
[*] [B]3rd reward:[/B] 9 minutes → Get cake
[*] [B]Continues up to 30 minutes, then repeats every 30 minutes![/B]
[*] Players are notified when next reward is available
[/LIST]

[B][COLOR=#8B0000]🐛 Bug Fixes[/COLOR][/B]
[LIST]
[*] [B]Fixed:[/B] Messages now auto-merge on update (no more "Missing message: darkness")
[*] [B]Fixed:[/B] Darkness effect now uses BLINDNESS (more visible across versions)
[*] [B]Fixed:[/B] Enhanced trapdoor sounds with multiple layers for creepier effect
[*] [B]Fixed:[/B] Config sections auto-merge on updates
[/LIST]

[SIZE=5][B][COLOR=#FFD700]⚙️ Configuration[/COLOR][/B][/SIZE]

[B]config.yml:[/B]
[CODE]intervals:
  darkness:
    min: 10    # Minimum minutes between darkness events
    max: 50    # Maximum minutes between darkness events[/CODE]

[B]Adjust in real-time:[/B]
[CODE]/halloween set darkness <min> <max>

Examples:
/halloween set darkness 15 30  # More frequent
/halloween set darkness 30 90  # Less frequent
/halloween set darkness 5 10   # Very spooky![/CODE]

[SIZE=5][B][COLOR=#FFD700]🎃 All Features (v1.3.0 + v1.4.0)[/COLOR][/B][/SIZE]

[B]Configurable Pumpkin Helmet Buffs:[/B]
[LIST]
[*] Customize which buffs are applied when wearing carved pumpkin
[*] Set individual effect levels (1-5+)
[*] Enable/disable specific effects
[*] Toggle glowing effect
[*] 8 admin commands for real-time buff management
[*] Supports all Minecraft potion effects (SPEED, HASTE, STRENGTH, REGENERATION, NIGHT_VISION, etc.)
[/LIST]

[B]Example Buff Commands:[/B]
[CODE]/halloween buffs list              # Show all buffs
/halloween buffs add NIGHT_VISION 1  # Add Night Vision I
/halloween buffs remove STRENGTH     # Remove Strength
/halloween buffs level SPEED 2       # Change Speed to Level II
/halloween buffs toggle              # Enable/disable all buffs[/CODE]

[SIZE=5][B][COLOR=#FFD700]🔧 All Commands[/COLOR][/B][/SIZE]

[B]Player Commands:[/B]
[CODE]/halloween help           - Show all commands
/halloween enable         - Enable Halloween effects for yourself
/halloween disable        - Disable Halloween effects for yourself[/CODE]

[B]Admin Commands:[/B]
[CODE]/halloween on/off                        - Global Halloween mode toggle
/halloween set <event> <min> <max>        - Adjust event intervals
/halloween reload                         - Reload configuration
/halloween reset <pumpkin|helmet|all>     - Reset player states

Buff Commands:
/halloween buffs list                     - Show all pumpkin buffs
/halloween buffs toggle                   - Enable/disable buff system
/halloween buffs add <effect> <level>     - Add buff
/halloween buffs remove <effect>          - Remove buff
/halloween buffs enable/disable <effect>  - Toggle specific buff
/halloween buffs level <effect> <level>   - Change buff level
/halloween buffs glow <on|off>            - Toggle glowing effect[/CODE]
