Configuration Files

config.yml - Main plugin settings (smart-merged on upgrades: your values and comments are kept, new keys are appended)
• Per-event enabled flags and intervals (events: section)
• World blacklist and player filters (vanish, spectator)
• Join messages, login pumpkin, helmet rewards
• Boss stats and rewards (pumpkin_zombie_boss, pumpkin_skeleton_boss)
• Grave system (waves, timeouts, rewards, chest glow)
• Pumpkin Trader trades (item: CANDY = Halloween Candy) and the candy item / drops
• Pumpkin buffs (effects, levels - 1 = Effect I, glowing)
• Season scheduler, witching hour, Discord webhook, statistics, visuals (boss bars, titles), WorldGuard
• Custom command prefix, update checker

messages.yml - Every text the plugin shows (events, help, admin feedback, boss bars, titles, Discord)
• Each category is a list, one entry is picked at random
• Colours: & codes (&c, &l ...), hex &#RRGGBB or § codes
• Placeholders are case-insensitive (%player% = %PLAYER%); %COMMAND% is the configured command name
• Categories you customise are never overwritten; new categories are appended on upgrades
• A YAML typo (e.g. unclosed quote) is reported with line/column, the file is left untouched and defaults are used until you fix it

data.yml - Player data (auto-generated)
• Global enable/disable state, player opt-outs
• Pumpkin curse counts, easter egg and helmet reward states
• Boss and grave cooldowns, season scheduler state

stats.yml - Statistics (auto-generated, saved every 5 minutes and on shutdown)
• Per-player counters: scares, pumpkins_received, halloween_mob_kills, bosses_spawned, bosses_defeated, graves_started, graves_completed, grave_mvp, cakes, candy_earned, pumpkin_time

World Blacklist, Player Filters & WorldGuard

worlds_blacklist - no events, buffs, rewards, bosses, graves or traders in the listed worlds (default: nether / the_end and their world_ variants). Multiverse-friendly: list any world name.

player_filters.respect_vanish - players hidden by a vanish plugin (SuperVanish, PremiumVanish, Essentials, CMI - anything setting the standard "vanished" metadata) get no events and are never named in broadcasts.
player_filters.skip_spectators - spectators get no events, buffs or rewards.

WorldGuard (optional): when WorldGuard is installed the plugin registers the region flag halloween-events (allow by default).
/rg flag <region> halloween-events deny → no scare events, bosses, graves or Pumpkin Traders inside the region (spawn, market...).

Not sure why a player gets nothing? /halloween debug eligible <player> lists every condition.

Season Scheduler

season:
  enabled: false
  start: "10-01"      # MM-DD
  end: "11-05"        # MM-DD (may be before start to wrap the new year)
  countdown_days: 7   # players joining up to N days before the start see "Halloween starts in N days"
  timezone: ""        # e.g. Europe/Prague, empty = server default

Halloween turns itself on when the season starts and off when it ends (checked every minute). Only the boundary crossings are applied, so /halloween on|off still works manually in between. When the season ends the top players (statistics.season_end_top / season_end_stat) are announced in game and on Discord.

Halloween Candy & Pumpkin Trader

Halloween Candy is a tagged item (ordinary cookies are not accepted) that drops from grave mobs, random pumpkin mobs, bat witches and appears in boss/grave chests (candy.drops). It cannot be eaten unless candy.edible: true.

[CODE]
candy:
  enabled: true
  material: COOKIE
  name: "&6&lHalloween Candy"
  lore: ["&7Sweet loot from the spirits.", "&7Trade it with the Pumpkin Trader!"]
  edible: false
  drops:
    grave_mob:          { chance: 0.25, min: 1, max: 1 }
    grave_complete:     { chance: 1.0,  min: 5, max: 10 }
    random_pumpkin_mob: { chance: 0.30, min: 1, max: 2 }
    boss_defeat:        { chance: 1.0,  min: 5, max: 10 }
    bat_witch:          { chance: 0.50, min: 1, max: 3 }
[/CODE]

Pumpkin Trader: right-click any villager while holding a carved pumpkin (it consumes one pumpkin). The trader keeps level 1 and offers exactly the trades from config:

[CODE]
pumpkin_villager:
  enabled: true
  trades:
    - cost:   { item: EMERALD, amount: 1 }

      result: { item: GOLDEN_APPLE, amount: 1 }
      max_uses: 5
[/CODE]

Existing traders pick up changed offers automatically (on startup and when opened). /halloween candy give <player> <amount> hands out candy manually.

Boss Battles

Pumpkin Zombie Boss (formerly Pumpkin Monster):
Summoning: Place fence + carved pumpkin on top, ignite with flint & steel

Minions: Spawns Cursed Bat (every 10s) and Haunting Phantom (every 60s)

Prevents high-level XP exploits while rewarding lower levels fairly

Protection:
Players who disabled Halloween effects (/halloween disable) cannot spawn bosses
Prevents opt-out players from exploiting boss rewards

Grave System

Build elaborate graves to summon an undead army!

How to Build:
1. Place 3 wood planks underground (coffin)
2. Cover with 3 dirt blocks above planks
3. Place RIP sign on middle dirt block
4. Build cross with stone walls (4 vertical + 2 horizontal at 3rd level)
5. Place candles on opposite side from cross
6. Light candle with flint & steel to trigger!

What Happens:
18-second dramatic animation (cross sinks → dirt vanishes → coffin transforms to nether bricks)
Undead army spawns: 3 Skeletons, 2 Zombies, 2 Skeleton Riders, 3 Zombie Riders
All mobs wear pumpkin helmets and glow
Buffed stats: +30% health, +50% damage, +20% speed

Rewards:
A glowing chest appears (outline visible until opened) with: 10-32 pumpkins, 2-5 cakes, skeleton skulls (50% chance), zombie heads (50% chance), 5 diamonds, 2-4 ancient debris, treasure map
Team-based XP distribution (XP split based on kill contribution)
Wave bar with countdown and titles for every wave; rewards scale with the overall completion of all waves; money: rewards are split by kill share, command: rewards run for every participant

Protection:
Disabled players cannot trigger graves
Helpful message shows if disabled player tries to activate

Troubleshooting

Buffs not applying?
→ Check /halloween buffs list - is pumpkin_buffs.enabled true?
→ Ensure player is wearing a CARVED_PUMPKIN (not jack-o-lantern)
→ Try /halloween reload

Event enabled: false not working?
→ UPDATE TO v3.0.0! This was fixed in the major update
→ After updating, use /halloween reload
→ Or set intervals to 0 0: /halloween set pumpkin 0 0

Commands not working?
→ Verify you have halloween.admin permission for admin commands
→ If using custom command prefix, use your configured command (e.g., /scary)

Boss not spawning?
→ Ensure correct structure: fence/lapis + carved pumpkin on top
→ Light the pumpkin with flint & steel (not torch)
→ Make sure you haven't disabled Halloween with /halloween disable

Grave not activating?
→ Check structure carefully - follow build guide exactly
→ Ensure RIP sign is on middle dirt block
→ Light the candle (not the sign)
→ Disabled players cannot activate graves

Custom command not working?
→ After changing command_prefix, do a FULL server restart (not /reload)
→ Verify console shows "Registered custom command"

Bat transformation not working?
→ Ensure bat_transformation.enabled: true in config.yml
→ It's only 33% chance by default (configurable)
→ Use /halloween reload after config changes

XP errors in console?
→ UPDATE TO v3.0.0! XP errors were fixed in all 3 locations
→ No more "Experience must be positive" errors

Old Halloween folder still present?
→ v3.0.0 uses Halloween_Softici folder to prevent conflicts
→ Manually migrate data.yml: copy plugins\Halloween\data.yml plugins\Halloween_Softici\data.yml
→ After verifying everything works, delete old Halloween folder

"A player gets no events / boss bars / titles"
• Run /halloween debug eligible <player> - it shows the global state, opt-out, world blacklist, vanish, spectator and WorldGuard checks
• The Nether and End are blacklisted by default (worlds_blacklist)

"money: rewards do nothing"
• Vault AND an economy plugin (e.g. EssentialsX) must be installed; the console says "no economy plugin registered" otherwise

"My Pumpkin Trader still shows the old trades"
• Open it once (or /halloween reload) - offers are synchronised with pumpkin_villager.trades
