[SIZE=4][B]🎃 Two Epic Boss Battles[/B][/SIZE]

[B][COLOR=#00AA00]Pumpkin Monster (Zombie Boss)[/COLOR][/B]
[LIST]
[*]Summon: Place [B]Fence Block[/B] + [B]Carved Pumpkin[/B] on top, right-click with Flint & Steel
[*]Stats: 100 HP, Diamond Armor, Mace weapon
[*]Rewards: Pumpkins, Cakes, Zombie Head, Glowstone, Phantom Membrane
[*]XP: Smart scaling (3-5 levels at low level, scaled XP at high level)
[/LIST]

[B][COLOR=#0066FF]Halloween Boss (Skeleton Boss)[/COLOR][/B]
[LIST]
[*]Summon: Place [B]Lapis Lazuli Block[/B] + [B]Carved Pumpkin[/B] on top, right-click with Flint & Steel
[*]Stats: 100 HP, Netherite Armor, Bow weapon
[*]Special: Summons [B]Bats[/B] every 10s and [B]Phantoms[/B] every 60s
[*]Rewards: [B]Ancient Debris[/B], Phantom Membrane, Random Beneficial Potion, 15-30 Pumpkins
[*]XP: Smart scaling (+40% more than Pumpkin Monster)
[/LIST]

[SIZE=4][B]💎 Pumpkin Trading System[/B][/SIZE]
[LIST]
[*]Right-click any villager with a Carved Pumpkin to convert them
[*]Becomes [B]Pumpkin Trader[/B] (Toolsmith with pumpkin helmet)
[*]Trade: [B]64 Pumpkins ↔ 1 Emerald[/B] (both directions)
[*]Daily limit: 64 trades per villager
[/LIST]

[SIZE=4][B]🎲 Random Pumpkin Mobs[/B][/SIZE]
[LIST]
[*]10% chance for any mob to spawn with a pumpkin helmet
[*]Drops 5-10 carved pumpkins when killed
[*]Works with all hostile mobs
[/LIST]

[SIZE=4][B]⏰ Join Cooldown System[/B][/SIZE]
[LIST]
[*]Players receive pumpkin helmet when joining (if not already wearing one)
[*]30-minute cooldown prevents pumpkin farming
[*]Persistent across server restarts
[/LIST]

[SIZE=5][B][COLOR=#FF6600]🎯 SMART XP SYSTEM[/COLOR][/B][/SIZE]

[B]No more XP exploits![/B] The plugin now scales XP rewards based on player level:

[LIST]
[*][B]Low Level (< 30)[/B]: Get direct levels (3-7 levels per boss)
[*][B]High Level (≥ 30)[/B]: Get raw XP that scales naturally with level requirements
[*][B]Halloween Boss[/B]: Gives +40% more XP than Pumpkin Monster
[/LIST]

[B]Examples:[/B]
[CODE]
Level 5:  Pumpkin Monster = +3 levels | Halloween Boss = +7 levels
Level 50: Pumpkin Monster = +70 XP (~0.4 levels) | Halloween Boss = +147 XP (~0.8 levels)
Level 90: Pumpkin Monster = +70 XP (~0.04 levels) | Halloween Boss = +147 XP (~0.09 levels)
[/CODE]

[SIZE=5][B][COLOR=#FF6600]📋 COMMANDS[/COLOR][/B][/SIZE]

[SIZE=4][B]Player Commands[/B][/SIZE]
[CODE]
/halloween help       - Show all commands
/halloween enable     - Enable Halloween for yourself
/halloween disable    - Disable Halloween for yourself
[/CODE]

[SIZE=4][B]Admin Commands[/B][/SIZE]
[CODE]
/halloween on                              - Enable Halloween globally
/halloween off                             - Disable Halloween (despawns bosses, reverts villagers)
/halloween reload                          - Reload config and messages
/halloween set <event> <min> <max>        - Set event intervals
/halloween reset <pumpkin|helmet|all>     - Reset player states
/halloween buffs list                      - List all pumpkin buffs
/halloween buffs toggle                    - Toggle buffs on/off
/halloween buffs glow <on|off>            - Toggle glowing effect
/halloween buffs add <effect> <level>     - Add a buff
/halloween buffs remove <effect>           - Remove a buff
/halloween buffs enable <effect>           - Enable a buff
/halloween buffs disable <effect>          - Disable a buff
/halloween buffs level <effect> <level>   - Change buff level
[/CODE]
